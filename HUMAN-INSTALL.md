# Humanese Install Instructions

Installation of the Animalese Desktop Application depends on what kind of computer you have.

If you are a "normal person", and not a software developer, you should follow the these instructions.

If you are a software developer, chances are you didn't need to read this, and you ignored this page completely.

First, navigate to the [Releases](https://github.com/joshxviii/animalese-typing-desktop/releases/latest) page. Releases is a special place on GitHub that allows you to download the "result" of the fancy code that you find on this website. Most of the software made available for people on this website can be found in the Releases portion of a GitHub site (known as a repository).


## Mac OS
> If you are using an iMac, MacBook, Mac Studio, Mac Mini, or any other Apple computer, this is the section you want to read for how to install

If you are using a Mac, there is a simple way to determine what version of this software you should install.

At the very top left of your screen, there is an Apple logo. When you press it, a menu will appear.

Press the "About This Mac", or whichever button says something similar. Apple may have changed the words used to describe the menu option, but if the words "About" and "Mac" are on the same line, that is the one you want to select.

A popup will appear in middle of your screen. If you read the contents of it carefully, you will see a piece of text describing what "Chip" your computer has. Pay attention to the words described in that area, as it tells you which link to press on the [Releases](https://github.com/joshxviii/animalese-typing-desktop/releases/latest) page.

Now that you have confirmed what kind of chip your mac you has, pay attention to the section on Releases that says "Assets". That section just means "things you can download".

If your About Mac window mentions an "Intel" chip, you want to download and run `AnimaleseTypingSetup-x64.dmg`. The `.dmg` means that it is meant for a mac, and the `-x64` part of the word means that it is put together specifically for the "Intel" chip. If your About This Mac screen says it has an intel chip, `-x64.dmg` means "for an intel mac".

If your About Mac window mentions an "Apple" chip (M1, M2, M3), or you have a MacBook Neo, you want to download the `AnimaleseTypingSetup-arm64.dmg`. The `.dmg` ending means it was built for Mac, and the `arm64` indicates it was builter for newer Macs. `-arm64.dmg` means "for macs with Apple chips".

## Windows
> If you are looking to install this application, and you are using a computer running Windows, this is the section you want to read.

Unless you are running an extremely old version of windows on an old computer, there is a single option to select for you.

Under the Assets section, click on `AnimaleseTypingSetup-x64.exe`. The `.exe` means "Executable" (aka - "I can run this in windows"). Download this and run it.
